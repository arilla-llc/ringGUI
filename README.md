# Лицензии 1С — RingGUI

Открыл — и все программные лицензии 1С на компьютере как на ладони.

**RingGUI** — бесплатная оконная оболочка над утилитой лицензирования 1С `ring`. Больше не нужно вспоминать команды вида `ring license info --name ...` и разбирать вывод в чёрном окне: программа сама находит все лицензии и показывает их карточками.

## Возможности

- **Мои лицензии** — при открытии сразу показывает все активированные лицензии со всеми сведениями (номер, продукт, владелец, адрес и т.д.). Кнопка «Скопировать всё» — для письма или документа. Кнопка «Проверить» — действительна ли лицензия на этом компьютере.
- **Активация** — форма вместо команды из двадцати ключей. Данные организации запоминаются, пин-коды — нет. Есть кнопка «Показать команду», если нужно выполнить вручную.
- **Диагностика** — проверяет Java, `JAVA_HOME`, `PATH`, наличие `ring` и папку лицензий. Для каждой проблемы — кнопка исправления, ссылка на загрузку и пошаговая инструкция.

## Требования

- Windows 10 / 11 (PowerShell 5.1 уже встроен)
- 64-битная Java 11 или новее — например, [Liberica JDK](https://bell-sw.com/pages/downloads/)
- [Утилита администрирования лицензий 1С (ring)](https://releases.1c.ru/project/EnterpriseLicenseTools) — нужен доступ к порталу 1С:ИТС

Если чего-то не хватает, программа сама откроет «Диагностику» и подскажет, что сделать.

## Установка и запуск

1. Скачайте [`RingGUI.cmd`](RingGUI.cmd) (кнопка *Download raw file*).
2. Щёлкните по файлу правой кнопкой → **Свойства** → поставьте галочку **«Разблокировать»** → ОК.
   Без этого Windows (SmartScreen / «Интеллектуальное управление приложениями») может заблокировать файл, скачанный из интернета.
3. Запустите двойным кликом.

При первом запуске на рабочем столе появится ярлык **«Лицензии 1С»** — дальше открывайте через него, тогда не мелькает даже окно командной строки.

Права администратора нужны только для активации — программа сама предложит перезапуститься с ними.

## Как это устроено

Вся программа — один файл. Его начало — несколько строк командного файла, которые запускают PowerShell, а остальное — PowerShell-скрипт с интерфейсом на WPF. Ничего не устанавливается и не компилируется, исходный код целиком можно прочитать в любом текстовом редакторе.

Программа только вызывает `ring` с нужными параметрами и красиво показывает ответ.

## Безопасность и данные

- Программа никуда не отправляет данные сама. В интернет обращается только `ring` при активации лицензии — к серверу лицензирования 1С.
- Данные организации для формы активации сохраняются локально в `%APPDATA%\RingGUI\profile.json`. Пин-коды не сохраняются.
- Ошибки пишутся в `%TEMP%\RingGUI.log`.
- Кнопки «исправить автоматически» в диагностике меняют только переменные среды текущего пользователя (`JAVA_HOME`, `Path`).

## Частые вопросы

**Обязательно ли ставить Java?** Да: `ring` — это Java-программа, а файлы лицензий зашифрованы и читаются только через неё. Если Java уже есть, но не прописана в `PATH`, программа найдёт её через `JAVA_HOME`.

**Можно ли активировать лицензию без всего этого?** Да — обычную клиентскую лицензию можно активировать мастером прямо в платформе 1С при запуске. RingGUI удобен, чтобы видеть все лицензии сразу и работать с ними на сервере.

**Программа сразу закрывается.** Посмотрите `%TEMP%\RingGUI.log` и создайте [issue](../../issues) с текстом ошибки.
